export function formatPrice(cents) {

export function total(items) {
  return items.reduce((sum, i) => sum + i.cents * i.qty, 0);

          Why not just open a few terminals?

          You can run Claude Code in a few tabs, and it's the same agent in Relay. The difference is what happens between the tabs.

            Private by design.

            Relay runs on your Mac. Beyond the agents you start, it only reaches GitHub: to check for a new release, and to publish a page when you ask.

            Local only

            The server listens on 127.0.0.1. Every request needs this install's secret and must come from Relay's own page.

            A key per agent

            Each agent gets its own token that only reaches its board tools. The master secret never goes in its config.

            You stay in charge

            Agents start in "Ask me" mode. A lead can't type into or stop others without your OK, and merging always asks.

            The Mac app uses the hardened runtime, with Electron's run-as-Node and inspector switches turned off. One honest caveat: an agent with shell access runs as you, so it can read what you can. Real isolation would need a separate macOS user.

            Questions? Answers.

            What do I need to run it?

            A Mac with Apple silicon on macOS 13 (Ventura) or later, and Claude Code installed and signed in. Codex, Gemini CLI and Cursor Agent are optional: install any of them and they show up in the New menu. They run in their own panes with your own logins, but only Claude Code agents get the board's tools.

            How is this different from a few Claude Code terminals?

            It runs the same claude CLI, with your login. What it adds: a git worktree for each worker, a lead that plans on a shared Board, agents that can message each other, one grid for status, one Review tab for every diff, and cost per pane. For one quick job, a single terminal is fine. See the comparison.

            How do I know the download is safe?

            Check its SHA-256 against GitHub's, look at how it's signed, and compare the app's code with the source at that version. The verify guide has every command, and what we found when we ran them on 1.8.2.

            Does it need an API key, or cost anything extra?

            No. Relay is free and MIT-licensed, and agents run in real terminals with your own CLI logins, so Claude Code uses your normal subscription. The Spend view shows what the same work would cost at API prices, so you can see where it went.

            macOS says Relay can't be opened / not verified

            That's expected on first launch. Relay is open source and unsigned, because it isn't enrolled in Apple's developer program yet, so macOS can't verify who made it. Either of these fixes it:

            1. Click Done, open System Settings → Privacy & Security, scroll down and click Open Anyway next to Relay, then confirm.
            2. Or run this in Terminal:
              xattr -dr com.apple.quarantine "/Applications/Relay.app"
            Where does my data live?

            The board, settings and secret are in ~/Library/Application Support/Relay (or …/Agent Desk if you used Relay when it was called Agent Desk). Agent worktrees and screenshots go in .agent-desk/ inside each project, which is kept out of git.

            How does it update?

            The version pill next to the logo checks GitHub releases. When a newer one is out it says Update, and one click downloads the new .dmg to your Downloads folder. If GitHub's API is rate-limited, as it can be on a shared office network, it falls back to the release page (since 1.9.10). If an older version shows a rate-limit error, download the latest by hand once.

            With Update automatically on in Settings (the default), the Mac app downloads the new version in the background, checks its SHA-256, and installs it when you quit Relay, or when you click Restart to update. It never restarts on its own. If macOS blocks it, allow Relay in System Settings › Privacy & Security › App Management.

            Can I build it myself, or run it on an Intel Mac?

            You can build it yourself: clone a release tag, then run npm ci and npm run app. npm start runs it in your browser instead, and npm run dist builds a .dmg. Build it yourself has the exact steps. There's no Intel download, and building on an Intel Mac hasn't been tested.
